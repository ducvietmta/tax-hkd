# Hướng dẫn thay thế Video Livestream

1. Đặt file video định dạng MP4 (H.264), tỉ lệ 9:16 (ví dụ: 720x1280 hoặc 1080x1920) vào thư mục này với tên `live-demo.mp4`.
2. Component `<PhoneMockup videoSrc="/videos/live-demo.mp4" ... />` sẽ tự động phát video mới với độ mượt mà tối đa.
3. Nếu không có file video, hệ thống tự động kích hoạt Live Studio Canvas Engine với hiệu ứng ánh sáng, model và sản phẩm chuyển động chân thực.
